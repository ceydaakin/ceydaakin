### 🚀 What I work on

- **AI-powered mobile apps at [Sentez Inc.](https://github.com/Sentez-Inc)** — a portfolio of React Native / Expo iOS apps that recognize and value real-world objects (banknotes, coins, stamps, jewelry, vinyl, trading cards, …) using vision LLMs, plus productivity & lifestyle apps.
- **App-generation platform** — the internal `sentez` CLI and `@sentez/*` package suite that scaffolds a new production-ready React Native app from a shared template (auth, paywall, analytics, i18n, crash reporting wired in).
- **iOS build infrastructure** — centralized CI that builds every app on a self-hosted macOS runner with GitHub-hosted failover (`expo prebuild → pod install → fastlane match → fastlane`).
- **Serverless AI backends** — Firebase Cloud Functions in TypeScript using the Vercel AI SDK, OpenAI and Replicate, with Zod-validated inputs and Sentry tracing.
- **feast.** — a restaurant discovery product: Flutter mobile app, Python & Go backends, React web menus and a QR-driven marketing mini-game.
- **UseLocaly / prfect** — AI-native localization for mobile apps and developer tooling.
